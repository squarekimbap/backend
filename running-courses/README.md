# 러닝 코스 데이터

"어디 뛰지" 앱에 넣을 코스 원고와 이미지. **`data/*.json`이 유일한 원본**이고 나머지는 전부 여기서 생성된다.

```bash
python3 build.py              # 전체 다시 생성
python3 build.py gangwon      # data/gangwon.json 만
python3 enrich_routes.py --dry-run  # TMAP·고도 호출 후 검증만
python3 enrich_routes.py            # 경로·안내·체크포인트를 원본과 서버 번들에 저장
```

## 산출물

| 경로 | 내용 |
|---|---|

## 코스 하나의 구조

`05-data.md`의 `Course` 모델을 따른다.

```json
{
  "id": "seoul-banpo-10k",
  "n": "반포 한강 10km 왕복",
  "km": 10.0, "min": 58, "lv": "보통", "mood": "야경",
  "tags": ["초보 추천", "야경", "호수·강변"],
  "scene": "river", "time": "night",
  "src": "러너 후기",
  "photo": "https://tong.visitkorea.or.kr/...",
  "photoTitle": "반포한강공원",
  "photoLicense": "한국관광공사 · 공공누리 제1유형",
  "headline": "...", "subhead": "...",
  "body": [], "deep": [], "ops": [], "unsure": [],
  "sources": [{ "title": "...", "url": "https://...", "type": "community|official",
    "checkedAt": "2026-09-01" }],
  "poi": [{ "n": "...", "d": "...", "lat": 37.5, "lng": 127.0 }],
  "polyline": [[37.5, 127.0]],
  "guide": [{ "lat": 37.5, "lng": 127.0, "text": "직진" }],
  "checkpoints": [{ "id": "...-1", "name": "...", "lat": 37.5, "lng": 127.0,
    "audioSeconds": 20, "description": "..." }]
}
```

- `body` → 화면의 **어떤 길인지**
- `deep` → **더 알아두면 좋은 것**
- `ops` → **가기 전에 알아두면 좋아요**
- `unsure` → **아직 확인 중인 것**. 확인 못 한 항목을 지어내지 않고 여기 담는다
- `poi` → **지나는 곳**
- `sources` → 원고 작성 때 실제로 확인한 공식 자료·국내 러너 후기. 커뮤니티 문장은
  그대로 옮기지 않고 주행 조건만 요약하며, 변할 수 있는 정보는 `checkedAt`을 함께 남긴다
- `photo`·`photoTitle`·`photoLicense` → 대표 사진과 출처. 새 코스에서 사진을 확보하지 못하면 null일 수 있으며 앱은 기본 이미지를 사용한다

## 이미지

사진을 쓰지 않고 **직접 생성한다.** `05-data.md`에 기존 이미지가 Wikimedia CC BY-SA라 출시 전 촬영자 확인이 필요하다고 적혀 있었는데, 생성 이미지는 그 문제가 없다.

만드는 방식은 이렇다. `photo`에 적힌 한국관광공사 사진에서 색을 뽑아, 그 팔레트로 플랫 일러스트를 그린다. 실제 장소의 색감은 남고 저작권 문제는 없어진다.

**씬은 6종** — `05-data.md`의 지도 도형 어휘와 같은 값을 쓴다.

| 씬 | 성격 | 지도 도형 |
|---|---|---|
| `lake` | 호수 | 닫힌 폐곡선 |
| `city` | 도심 공원 | 닫힌 폐곡선 |
| `river` | 하천·강변 | 왕복 |
| `coast` | 해안 | 왕복 |
| `trail` | 숲길 | 편도, 구불구불 |
| `hill` | 업힐 | 편도, 지그재그 |

`time`은 `day` / `sunset` / `night`. 비워두면 원본 사진 밝기로 자동 판별한다. 밤은 별과 창문 불빛이 들어간다.

같은 씬끼리 똑같아 보이지 않도록 `id` 해시로 구도 변형 3종과 수평선 높이가 갈린다.

## 문구 규칙

`06-copy.md`를 따른다. **"검증·데이터·확보·실측·열림"은 화면에 쓰지 않는다.**
확인 못 한 정보는 숨기지 말고 `unsure`에 적는다.

코스마다 장소 이야기와 러닝 감각을 먼저 두고, 운영 정보만 나열하지 않는다. `가장`,
`유일한`, `압도적`처럼 근거가 필요한 표현은 공식 자료나 복수 후기로 확인된 경우가
아니면 쓰지 않는다. 원고 구조는 **어떤 길인지 → 더 알아두면 좋은 것 → 가기 전 정보**를
유지한다.

## 경로 데이터 갱신

- `data/*.json`의 POI·거리·원고를 먼저 고친 뒤 `enrich_routes.py`를 실행한다.
- 경로는 최대 200점이며 `[[lat,lng], ...]` 순서다. `guide`는 TMAP 안내 문구를 보존한다.
- 체크포인트 설명은 POI 원고에서 만들고 실제 경로 100m 안의 지점만 남긴다. `audioSeconds`는 예상 낭독 시간이며 음원 파일 길이가 아니다.
- 트레일 전용 코스(북한산·관악산·무등산)는 도시 코스에 흡수돼 있고 따로 분리하지 않았다.
