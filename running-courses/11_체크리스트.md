# 러닝 공통 체크리스트

## 안전
- **야간 러닝**: 반사 조끼 또는 LED 라이트 **필수** — 한강·하천 코스는 자전거 사고 위험이 실제로 큼
- 한강·하천길은 **자전거 전용도로와 보행·러닝 도로가 분리**돼 있음. 자전거도로 침범 금지
- 한강변 대부분 구간에 가로등·CCTV 완비, 한강공원·올림픽공원은 24시간 개방
- 이어폰은 한쪽만 쓰거나 골전도 권장 (자전거 벨소리 감지)

## 계절·시간대
| 상황 | 권장 |
|---|---|
| 여름 | 오전 9시 전 또는 오후 6시 후 |
| 겨울 한강 | 체감 -5~10℃ → 방풍 자켓 필수 |
| 미세먼지 | **PM10 80↑ / PM2.5 35↑ 이면 실내 대체** |
| 벚꽃철 주말 낮 | 여의도·석촌호수·경의선숲길·무심천은 피하고 이른 아침/평일 |
| 관광지 코스 | 새벽런 (전주 한옥마을, 송도 센트럴파크, 해운대) |

## 편의시설이 확인된 코스
- **샤워장**: 여의도·잠실 한강공원
- **물품보관·탈의실·파우더룸**: 여의나루역 러너스테이션 (런플 앱 예약)
- **코인라커**: 노들섬 (500원 동전 준비)
- **급수**: 한강 아리수 급수대, 일산호수공원 음수대, 진해 드림로드 약수터
- **편의점/화장실 다수**: 반포 10km 코스 (편의점 3, 화장실 5)

## 거리 계산이 쉬운 순환 코스
| 코스 | 1바퀴 |
|---|---|
| 창원 용지호수 | 1.2km |
| 석촌호수 | 2.5km |
| 송도 센트럴파크 | 3.5~3.8km |
| 올림픽공원 내부 | 3.5km |
| 경포호수공원 | 4.3km |
| 일산호수공원 | 4.7km |
| 경복궁 돌담길 | 2.6km (2바퀴 5.2km) |

## 트랙 (인터벌·기록 측정)
- 서울: 안양천 신정교 340m, 국회운동장
- 광주: 동구 체육공원 국제 규격 트랙 (상시 개방)
- 청주: 충북대 / 전주: 전북대 / 창원: 스포츠파크 보조경기장 400m

## 트레일 추가 준비물
- 트레일화(미끄럼 방지), 충분한 물, 간식, 레이어링 의류
- 국립공원은 **입산시간지정제·탐방로 통제현황** 사전 확인
- 초반엔 오르막 걷기 + 평지·내리막만 러닝 (부상 예방)
