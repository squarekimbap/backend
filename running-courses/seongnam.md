# 탄천, 분당에서 한강까지 끊기지 않고 이어지는 강변

10km든 20km든 원하는 만큼. 자전거도로가 분리돼 있어 긴 거리를 안전하게 채운다.

`15.0km` `92분` `보통` `평지`

[**지도에서 출발점 열기**  →](https://map.kakao.com/?q=탄천)

### 어떤 길인지

탄천은 성남과 분당을 잇는 강변 코스이고, 그대로 따라가면 서울 한강까지 연결된다. 10~20km를 어디서 끊느냐만 정하면 된다.

분당에서 한강 합류 지점까지 자전거도로가 분리돼 있어 긴 거리를 달릴 때 안전한 편이다. 러너온 자료에서는 하천형 약 8km 코스로 분류한다.

직선 강변이라 페이스 유지가 쉽고 갈림길 고민이 없다. 대회 준비 장거리 세션에 자주 쓰인다.

### 더 알아두면 좋은 것

구간마다 화장실과 주차장이 다르다. 출발 지점을 정한 뒤 지도에서 근처 생태공원 주차장과 공중화장실을 확인해두는 편이 정확하다.

짧게 끝내고 싶은 날은 율동공원 쪽 순환로로 바꾸면 된다.

### 가기 전에 알아두면 좋아요

- 긴 구간이라 급수 지점 간격이 넓다. 물은 챙기는 게 좋다.
- 출퇴근 시간대에는 자전거 통행량이 늘어난다.

### 아직 확인 중인 것

- 구간별 화장실 위치
- 한강 합류점까지 실제 거리
