# 내비게이션

## 주요 흐름

**첫 실행**  
`login` → `agree` → `onb` → `home`

**코스 골라 달리기**  
`home` → `detail` → `ready` → `run` → `done` → `home`

**코스 생성**  
`home` → `perm` → `gen` → `pick` → `making` → `detail`

**생성 실패 복구**  
`making` → `fail` → `making`

**공유**  
`detail` → `story`

**내 기록**  
`my` → `list2` → `rec`

**설정·탈퇴**  
`my` → `setting`

**탐색**  
`home` → `search` → `theme` → `detail`

## 화면 스택 규칙

스택 배열로 관리하고, 마지막 항목이 현재 화면이다.

| 규칙 | 내용 |
|---|---|
| push | `stack.push(id)` — 오른쪽에서 진입 |
| 스택 교체 | `stack = ["home"]` — 진입 흐름 종료 시 (약관→홈, 완주→홈) |
| 중간 화면 제거 | 생성 완료 시 `making`·`gen`·`pick`을 스택에서 뺀다. 러닝 완료 시 `run`·`lock`을 뺀다 |
| z-index | 현재 화면 10, 이전 9. DOM 순서와 스택 순서가 달라도 겹치지 않게 |
| 포인터 | 화면 밖 페이지는 `pointer-events: none`. 보이지 않는 버튼이 눌리는 것 방지 |

### 전환 애니메이션

| 항목 | 값 |
|---|---|
| 진입 화면 | `translateX(100% → 0)` |
| 이전 화면 | `translateX(0 → -26%)` + 10% 어둡게 |
| 길이 · 이징 | `0.36s` · `cubic-bezier(.32, .72, 0, 1)` |

> **주의**: 무거운 화면은 push를 먼저 시작하고 본문을 다음 프레임에 채운다.
> 렌더가 먼저 오면 트랜지션 시작이 약 90ms 지연되어 누른 뒤 멈춘 느낌이 난다.

## 탭 구조

```
홈  |  ◉ 생성 (탭바 중앙에서 16pt 솟은 원)  |  마이
```

- 생성 버튼은 탭이 아니라 별도 플로팅. 위치 권한이 없으면 권한 화면을 먼저 띄운다.
- 홈 상단은 `추천` + 사용자가 추가한 도시 + `[+]` 가로 스크롤 탭.
