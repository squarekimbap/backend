# 디자인 시스템

## 색 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg-1` | `#100F0E` | 기본 배경 |
| `--bg-2` | `#161514` | 시트·올라온 면 |
| `--sunken` | `#1F1E1C` | 카드 (배경보다 밝다) |
| `--sunken-2` | `#282725` | 카드 hover·구분 |
| `--ink` | `#F4F3EF` | 본문 |
| `--ink-muted` | `#8B8B83` | 보조 |
| `--ink-faint` | `#5C5C55` | 흐린 것 |
| `--on-ink` | `#100F0E` | 밝은 면 위 글자 |
| `카카오` | `#FEE500` | 유일한 색 예외 |

### 원칙

- 앱은 색을 만들지 않는다. 색은 사진과 카카오 버튼만 들여온다
- 어두운 테마에서 카드는 배경보다 밝다 (밝은 테마의 반대)
- 상태는 색이 아니라 채움으로 구분한다: 빈 링 = 미완료, 채운 원 = 완료
- 그림자 토큰을 만들지 않는다. 떠 있는 요소만 예외

> 라이트 변형에서는 카드가 배경보다 **어두워지고**, 생성 버튼이 흰 원 → **검은 원**이 된다.
> 잠금화면은 시스템 화면이므로 테마와 무관하게 항상 어두운 배경 + 흰 글자.

## 서체

| 항목 | 값 |
|---|---|
| 웹 프로토타입 | Pretendard Variable |
| iOS 실기기 | SF Pro + Apple SD Gothic Neo (시스템) |
| 고른 이유 | Pretendard가 SF 메트릭 기반이라 프로토타입↔실기기 차이가 가장 작다 |
| 숫자 | `monospacedDigit` 필수 — 거리·시간이 흔들리지 않게 |
| 줄바꿈 | 한국어 단어가 쪼개지지 않게 (`word-break: keep-all` 대응) |
