# 어디 뛰지 (Dali) — 개발 문서

여행지에서 관광지를 지나는 러닝 코스를 만들고, 체크포인트에 도착하면 그곳의 이야기가 열리는 iOS 앱.

## 문서 구성

| 파일 | 내용 |
|---|---|
| `01-design-system.md` | 색·서체·크기 토큰, 시스템 원칙 |
| `02-navigation.md` | 화면 스택, 전환 규칙, 주요 흐름 |
| `03-screens.md` | 화면 22개 명세 (구성·실측·규칙·iOS 참고) |
| `04-animation.md` | 애니메이션 타이밍과 접근성 |
| `05-data.md` | 데이터 모델, API, 에셋 |
| `06-copy.md` | 내부 용어 → 화면 문구 매핑 |
| `07-open-questions.md` | 구현 전 결정할 것 |

## 기준

모든 수치는 HTML 프로토타입을 브라우저에서 렌더링해 **실측한 값**이다. 추정치가 없다.

문서와 프로토타입이 어긋나면 **프로토타입을 따른다** (`eodi-run-prototype.html`).

## 앱 기본

- 화면 크기 375 × 812 (안전영역 상단 44 / 하단 34)
- 테마: 어두운 테마 기본 · 라이트 변형 있음 (`eodi-run-prototype-light.html`)
- 서체: SF Pro + Apple SD Gothic Neo (프로토타입은 Pretendard)
- 화면 22개 · 도시 21곳 · 코스 77개 · 이야기 28곳
