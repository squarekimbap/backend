### 로그인 애니메이션 상세

총 12.8초 무한 순환.

| 단계 | 길이 | 내용 |
|---|---|---|
| 그리기 | 3.0s | 경로가 그려지며 체크포인트 링이 순차 등장 (ease-out cubic) |
| 달리기 | 5.6s | 러너가 경로를 따라 이동, 지난 구간이 진해짐 (smoothstep) |
| 유지 | 2.4s | 완성 상태 유지, 러너 페이드아웃 |
| 되감기 | 1.8s | 경로와 체크포인트가 사라지며 처음으로 |

체크포인트 통과 시: 코어 페이드 320ms · 링 바운스 620ms · 반경 확산 1050ms

## 스크롤 연동

| 대상 | 동작 |
|---|---|
| 홈 카드 캐러셀 | 중앙에서 멀어질수록 scale 1 → 0.95, opacity 1 → 0.58 |
| 홈 무한 순환 | 목록 3벌을 쌓고, 양 끝 도달 시 한 벌 높이만큼 위치 보정 (스크롤 정지 후) |
| 코스 상세 상단 바 | 150pt 스크롤에서 배경 불투명 + 코스명 페이드인 (0.22s) |

## 접근성

`prefers-reduced-motion`(iOS: `UIAccessibility.isReduceMotionEnabled`) 대응:

- 화면 전환과 카드 축소·투명 효과를 끈다
- 로그인 애니메이션은 최종 상태만 정적으로 표시
- 스피너와 오디오 이퀄라이저는 멈추지 않되 느리게 (0.8s → 2.4s)
