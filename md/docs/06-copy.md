# 화면 문구

ADR-025의 canonical vocabulary는 내부에서 그대로 쓰고, **화면에는 사용자 말로 바꿔** 보여준다.

이 매핑을 코드 한 곳에 모아야 문구가 흩어지지 않는다.

## 내부 용어 → 화면 문구

| 내부 용어 (쓰지 않음) | 화면 문구 |
|---|---|
| ~~부분 검증~~ | **정보만 모았어요** |
| ~~경로 검증~~ | **길까지 확인했어요** |
| ~~현장 검증~~ | **직접 뛰어보고 확인했어요** |
| ~~데이터 출처~~ | **러너들이 올린 후기를 모았어요** |
| ~~경로가 확보되지 않았습니다~~ | **길 안내는 아직 준비 중이에요** |
| ~~아직 따라 달릴 수 없습니다~~ | **코스 정보만 볼 수 있어요** |
| ~~이야기 1/3 열림~~ | **들으면서 달리는 이야기 3곳 · 1곳 들었어요** |
| ~~100m 안에서~~ | **가까이 가면** |
| ~~운영·안전 메모~~ | **가기 전에 알아두면 좋아요** |
| ~~실측 여부~~ | **실제로 4.6km가 맞는지** |
| ~~생성 실패~~ | **여기서는 코스를 만들기 어려워요** |

## 신뢰 단계 표시

내부 6단계를 화면에서는 3단계 문장으로 묶는다.

| 내부 | 화면 문구 | 설명 |
|---|---|---|
| 현장 검증 | 직접 뛰어보고 확인했어요 | 거리와 길, 지나는 곳을 모두 확인했습니다 |
| 경로 검증 | 길까지 확인했어요 | 지도 안내를 따라 달릴 수 있습니다 |
| 생성됨 / 부분 검증 | 정보만 모았어요 | 거리와 지나는 곳은 후기를 정리한 것이라, 길 안내는 아직 준비 중입니다 |

## 출처 표시

| 내부 값 | 화면 문구 |
|---|---|
| 직접 제작 | 직접 다녀와서 정리했어요 |
| 공공 출처 | 지자체와 공공기관 자료를 확인했어요 |
| 러너 후기 · 관광공사 | 러너 후기와 관광공사 자료를 함께 봤어요 |
| 러너 후기 · 편집부 | 러너 후기를 모아 편집했어요 |
| 러너 후기 | 러너들이 올린 후기를 모았어요 |

## 원칙

- **'실패'라는 말을 쓰지 않는다.** 무슨 일이 있었는지 숫자로 설명하고 다음 선택지를 준다
- **비활성 버튼에는 할 수 있는 것을 쓴다.** "아직 따라 달릴 수 없습니다" → "코스 정보만 볼 수 있어요"
- **못 하는 것보다 할 수 있는 것을 먼저.** "거리와 지나는 곳은 믿고 보셔도 됩니다. 다만…"
- **미완성 정보는 참여 요청으로.** "직접 다녀오셨다면 알려주세요. 확인해서 바로 고칩니다"
- 개발 용어(데이터, 확보, 실측, 열림, polyline)를 화면에 쓰지 않는다
